# 画面规格（当前定稿版本）

本文件记录当前画面效果所依赖的关键参数，作为后续开发的基准。改动其中任何一项前，请先在 Demo 里对比截图（见文末「验证方法」），确认画质没有退化。

- 版本基准：Godot 4.7.2-stable（GL Compatibility 渲染器），见 README「环境要求」
- 参考画面：`pixel.jpg`；目标是「远看精致、近看清晰、移动时不闪烁」

### 贴图绘制规则
1. 大面积用可平铺值噪声做成片色块和多级明暗，不用逐像素随机杂点。
2. 结构线（板缝、瓦缝、石缝）1px 宽，旁边 1px 高光。
3. 细节用成簇的小笔触（草叶、针叶、石子），每个笔触有亮面和阴影。
4. 长条结构（码头甲板等）**不在贴图里画密集的高对比条纹**，缝隙用几何表现，否则远看会出摩尔纹。
5. 地面类贴图生成后 `flip_y`，保证俯视时「阴影在下」。

## 3. 光照与阴影

| 项目 | 当前值 |
|---|---|
| 阴影贴图 | 4096，软阴影质量 5（最高，`project.godot`），shadow_blur 1.0 |
| 阴影模式 | 平行分割 2 级，级联混合开启 |
| 阴影范围 | 随镜头距离自适应（`PWTimeOfDay.fit_shadows`）：总距离 `clamp(镜头距离 × 1.9 + 12, 40, 120)` 米；**第一级覆盖到镜头距离 × 1.35**，画面主体都在高精度级里 |
| 太阳运动 | **每 1 游戏分钟更新一次方向**（`shadow_step_minutes = 1`，一天 300 秒时约每 0.2 秒一次，每次转约 0.17°）；仰角 14°~60°，方位 -30° ± 70°；19:00~5:00 同一盏灯当月光 |
| 一天时长 | 300 秒（Demo 可选 60 / 300 / 1200） |
| 投影的物体 | 房屋、灯塔、树、灌木、石头、**栏杆 / 篱笆、路灯、长椅**、木箱木桶、角色 |
| 不投影的物体 | 地面（草地、湖底、野外地形）、水面、道路、土路、碎石带、水草、光斑 |

### 阴影规则（后续开发必须遵守）

1. **太阳方向不能每帧连续变化。** 方向一变，整张阴影贴图就要重新光栅化；细物体（栏杆横木约 11cm）的影子只占几个阴影像素，每帧重算就会像电流一样抖，树影的锯齿边缘也会来回爬。所以方向按 `shadow_step_minutes` 小步更新：每次只挪约 1 个像素，看起来仍是连续移动，但两次更新之间画面完全稳定。
2. **不要用两盏平行光交叉淡入来平滑过渡。** 兼容渲染器（含 Web）逐盏叠加带阴影的平行光，叠加不是线性的，两盏各一半亮度时整幅画面会明显发亮（实测差异 69 vs 正常 0.87）。
3. **画面主体要落在第一级阴影里。** 镜头距离变化时调用 `PWTimeOfDay.fit_shadows(距离)`；不要把 `directional_shadow_split_1` 写死。之前写死 0.35 时第一级只到 18.8 米，而镜头离地面 22 米，整个画面都在粗糙的第二级里，细阴影因此抖得最厉害。
4. **所有立着的物体都要投实时阴影**，包括细物体。不要用「接地暗影」之类的替代品，那样在中远景几乎看不见（已经试过，已删除）。
5. **平的、贴地的东西不投影**（地面、道路、水面、贴花），省阴影贴图开销。
6. **验证方法**：改动光照、阴影或细物体后，跑闪烁测试（第 9 节「阴影闪烁」），整个画面的 `toggles`（像素来回翻转次数）应 ≤ 5；当前约 4，太阳每帧连续转动时约 97。

## 7. 场景内容与变化

- **房屋**：门窗是独立 3D 部件（`pw_parts.gd`）；门色、百叶窗、窗格数、花箱、老虎窗、雨棚、屋顶颜色按房屋参数派生。
- **树**：10 种松树 / 冷杉 + 12 种阔叶树（橡树 6、白桦 3、杨树 3，不用红 / 橙色的秋色树）+ 8 种灌木 + 8 种石头，每个实例再随机朝向（任意角度）、宽高比例（±12% / -12%~+20%）和色调（±10%），场景里没有两棵一样的树。
- **树干规则**：乔木（松树、橡树、白桦、杨树）必须露出树干——俯视 40° 时树冠外伸多少就会挡住下面多高的树干，所以树冠最低处 ≥ 树冠外伸量 × 0.85 + 0.55 米（`_clear_height`）；根部略粗。只有灌木和花草没有树干。树干、树枝用 `MB.tube` / `wrap_uv`，贴图沿圆周展开，避免横向花纹连成圆环。
- **白桦**：微弯的三段白色主干（根部 0.23 米、树梢 0.05 米）+ 3~4 根斜枝，树冠是 9~13 个相互重叠的嫩绿叶团组成的椭圆冠；树皮 64px，成簇的黑色皮孔 + 深色疤痕。
- **路灯**：4 种款式（灯笼、悬臂、球形、双头）× 3 种金属色，每盏随机；悬臂灯伸向路面，光斑对准灯箱。
- **篱笆**：3 种（白色尖头栅栏、乡村木栏、矮石墙）；**长椅**：3 种（木条、公园绿漆、原木凳）。
- **码头**：独立甲板（宽 0.26 米，缝 3.5cm）+ 托梁 + 木桩 + 系船柱。
- **小路（森林 / 平原）**：A* 寻路后隔点取样 + 3 次 Chaikin 细分成圆滑曲线，再按 0.5 米等距铺成带状路面（宽约 1.45 米，两侧边缘随噪声起伏 ±0.12 米），每个点贴着地形起伏；不再是一格格方块。
- **平原地标**：农舍 + 木栏围起的田（草垛）、风车（叶片匀速转动）、营地。

### 草的规则（`PWGrass`，所有风格共用）

| 项目 | 规则 |
|---|---|

| 密度 | 风格给的基础密度 × 成团噪声（一片片长，中间露出地皮）：平原草地 1.0、森林草地 0.55 / 林下 0.19、小镇草坪 0.45 / 林带 0.25 |

### 摆放规则（`PWPlacement`，所有生成器必须遵守）

场景里的每个物体在放下之前都要先 `can_place`，通过了才 `add`；摆放顺序就是优先级（先放的不会被后放的挤掉）：
道路 → 土路 / 码头 → 地标（灯塔、营地等）→ 房屋和门前通道 → 路灯 → 篱笆 → 长椅 / 货物 → 树 → 灌木 → 石头。

每个物体登记两层占地：**地面层**（树干、灯杆、墙体）和**高空层**（树冠、灯头、屋檐）。两个物体都高于 2 米时，高空层也要满足间距——这就是之前「路灯和树重合」的根源：只比较了树干位置，没比较树冠和灯头。

| 规则 | 值 |
|---|---|
| 树冠 ↔ 灯头 | 净空 ≥ 0.6 米（灯光要照到地面） |
| 树冠 ↔ 屋檐 | 净空 ≥ 0.8 米 |
| 树冠 ↔ 道路上空 | 树冠的 60% 不能伸到路面上 |
| 树 ↔ 门前通道、地标 | ≥ 1.0 米 |
| 树干 ↔ 树干 | ≥ 1.6 米（树冠允许轻微交叠，形成自然的林子） |
| 路灯 ↔ 路灯 | ≥ 4 米；路灯 ↔ 门前通道 ≥ 0.8 米 |
| 房屋 ↔ 房屋 | ≥ 1.5 米；房屋 ↔ 道路 ≥ 1.2 米 |
| 每栋房子 | 正门朝路，门前保留 1.8 米宽的通道直到路边，通道里什么都不能放 |
| 森林 / 平原 | 地形是平滑的连续高度场（不做台阶），丘陵起伏幅度按风格（森林 4.2 米、平原 1.6 米）；地表按「高度 × 坡度 × 湿度」在 shader 里混合草 / 沙 / 岩石 / 湖底（顶点权重 + 噪声边界，`terrain_mode`）；树种在坡度 < 0.45 处并按坡度下沉，兴趣点脚下压平；坡度 > 0.75（约 37°）不可通行 |
| Blender 摆件（小镇） | 石井、集市摊位放在路边、正面朝路，类别 PROP：离道路 ≥ 0.3 米、离土路 ≥ 0.4 米、离门前通道 ≥ 0.6 米 |

完整的类别间距表见 `pw_placement.gd` 的 `GAP`。生成结束后 `validate()` 再整体复核一次，结果在 `PWWorld.violations`。
回归测试：`godot --headless --path godot --script res://tests/test_world_gen.gd`，三种风格（小镇 / 森林 / 平原）× 5 个种子，要求全部 0 违规、路灯与树逐对复核通过、出生点能站人、土路接到道路、自然风格没有小水坑、能另存为场景；`tests/test_fish.gd` 检查鱼不会游上岸。

## 8. 角色（像素精灵，和场景同一套像素网格）

2026-11-15 起是全像素风：人物和场景用同一个像素密度、同一个俯角，人物是正常头身比（约 6 头身、身高 1.72 米），
不再是 Q 版大头。

| 参数 | 值 | 说明 |
|---|---|---|
| 帧尺寸 | 80 × 80 像素 | 32 像素 / 米，和场景贴图 32 texel / 米相同；角色约 50 像素高 |
| 身体比例 | 骨盆 0.86、肩 1.38 米，大腿 0.42 / 小腿 0.40，上臂 0.30 / 前臂 0.26，头以下巴为中心缩到 0.62 | `sprites.py` 顶部的常量；资产工坊动作编辑器用同一组数 |
| 眼睛 | 约 1~2 像素的小点，2×2 合并时只要有一个子像素是眼睛就保留 | 太小的高光点不画 |
| 方向 | 8 个（每 45°） | 第 d 行 = 镜头从角色正面逆时针（俯视）转 d×45° |
| 动画 | 待机 4 帧（4 fps）+ 走路 6 帧（10 fps） | 走路帧率随移动速度缩放 0.6~1.4 倍 |
| 渲染 | Blender Workbench 正交，俯角 40°（= 游戏镜头俯角），2 倍超采样后 2×2 合并 | 部位取多数票，边缘干净无噪点 |
| 上色 | 每个部位三色色阶，按 N·L 分三档（阈值 0.62 / 0.18），主光从左上前方 | 所有方向的帧光照一致；眼睛不分档、带 1 像素白色高光 |
| 描边 | 轮廓外 1 像素，相邻部位最深色 × 0.7 + 墨色 #1d2030 × 0.3 | 部位自己的暗色，不是近黑，不会像贴纸 |
| Godot 显示 | Y 轴公告板，竖向拉长 1/cos(40°)（catalog 的 `elev_deg`），从 40° 俯视看过去不变形、精灵像素和渲染像素一一对应；最近邻、alpha 剪切 0.5、投射阴影 | 贴图导入：无损、不生成 Mipmap、`detect_3d/compress_to=0`（不能变成 VRAM 压缩，会糊） |
| 光照 | wrap 光照，背光最暗保留 55%；接收阴影（进树荫变暗） | 夜里随环境变暗，路灯下变亮 |
| 自阴影 | 影子 pass 里投影板随高度往背光方向斜（每米 0.9 米，必须 ≤ 1） | 沿光线方向平移不改变地上影子的位置；超过 1 会让脚下的影子消失 |

新增角色：在 `sprites.py` 的 `PRESETS` 里加一项（部件 + 每个部位的三色色阶，颜色尽量取自调色板或相近色），
再运行 `blender -b --factory-startup -P tools/blender_build_sprites.py -- --only <id>`。

## 9. 特效与主界面预览

- **特效库分三类**：天气（晴、多云、雨、雷暴、雪、暴风雪、雾）、环境（白天、黄昏、夜晚灯光、雨夜、水面）、动作（`PWVFX`，11 种，分攻击 / 受击 / 法术 / 增益 / 移动）。
- **切换天气是立即生效的**：从积雪切回晴天，地面积雪、潮湿、雪 / 雨粒子马上清掉。
- **动作特效材质**（`vfx.gdshader`）：预乘 alpha 混合，`cover` 控制盖住背景的程度（白天亮背景下也能看出颜色，不会一片白），
  `rim = 1` 时中间透明、边缘亮（护盾）；透明度分 5 档；消散时按像素格子随机溶解。粒子是小方块像素点（0.04~0.09 米）。
- **预览窗口不自动旋转**：底部按钮（左转、右转、抬高、压低、放大、缩小、重置），鼠标悬停时键盘 ←→ 旋转、↑↓ 俯仰、WASD 平移、+/- 缩放、R 重置；
  左键拖动旋转，右键 / 中键拖动平移，滚轮缩放。
- **资源库展示数量**：会成片出现的（树、灌木、草、岩石）随机撒几个，每个都不一样；有固定款式的（路灯、篱笆、长椅、Blender 资产）排出全部款式；
  独一个的（角色、房屋、地标）只放一个。场景生成器的预览不显示草地圆台（会挡住水面）。

### 资产统一用 Blender 版

场景里出现的所有模型都由 Blender 生成（`blender/pixel_world_blender/generators/`），资源库和所有场景生成器都用 Blender 版，
Godot 代码版只在没有 `godot/assets/blender/catalog.json` 时兜底：

| 类别 | Blender 资产（变体数） |
|---|---|
| 树 / 植物 | 松树 10、橡树 8、白桦 8、杨树 6、灌木 8、石头 8、草丛 6（4 普通 + 2 高草）、干草 4、花草 4、水草 3 |
| 建筑 / 地标 | 小镇房屋 14、农舍 4（林间小屋 / 农场）、灯塔 4、风车塔身 3 + 叶片 3（叶片单独转动） |
| 街道 / 杂物 | 路灯 6、篱笆 4 款 + 篱笆柱 4 款、长椅 3、木箱 3、木桶 3、草垛 4、井、集市摊位、手推车、路牌 |
| 水里 | 小鱼 2（橙 / 银） |

- 尺寸不一的资产（房屋、农舍）在 catalog 里有每个变体的 `variant_info`（占地、宽、深、层数），场景按真实尺寸排布局；
- 篱笆是 2 米一段的模块（左端自带柱子），按长度微调拉伸、末尾补一根柱子，门口两侧都有柱子；
- 导入时按材质修顶点：草叶法线偏上（背面不发黑）；窗玻璃每块随机一个顶点 alpha，夜里有的亮有的不亮；
- 峡谷 / 沙漠的石头乘红褐色调（风格参数 `rock_tint`），和红岩地貌一致。
- Blender 材质按材质键共用一份（贴图是同样的种子画的），合批不会因此多出绘制调用；
- 植被合批前把带索引的网格展开成逐三角形（Blender 导入的 glb 都带索引）；
- 路灯的光斑按模型实际的灯头位置放：单臂灯在灯头下、双臂灯在灯柱下；灯塔的门朝向小镇。

## 9c. 移轴与像素模式

| 参数 | 值 | 说明 |
|---|---|---|
| 移轴清晰带 | 中心 0.55、半宽 0.18（屏幕高度比例） | 带边缘用 smoothstep 过渡，看不出分界线 |
| 移轴最大模糊 | 3.2 像素（720p 基准，按分辨率等比放大） | 画面上方（远处）再乘 1.3，更像微缩模型；16 个采样点、线性过滤 |
| 像素模式（默认开启） | 缩放倍数 = 屏幕高 ÷（画面纵向米数 × 32），四舍五入、至少 1 | 走路镜头（22 米）：720p / 1080p 都是约 360 行，贴图和人物 1:1；拉远后自动减小倍数，贴图细节不丢 |
| 像素对齐 | 镜头沿自己的右 / 上方向对齐到渲染像素网格，零头用整个画面平移补回 | 静止和慢速平移时画面完全不变（`--diffshot` 变化 0%），没有「爬像素」闪烁 |

## 9d. 地表打散平铺与自然地貌

**远处看不出一格一格（平原 / 雪地 / 所有地形）**：
- 贴图「炸弹式」采样：原样和转 90° 错开的两套坐标，按低频噪声二选一，交界逐贴图像素抖动；远处向贴图平均色淡出 40%；
- 大尺度明暗 / 干湿起伏：旋转 3 层 fBm（打散值噪声的方格痕迹）+ 域扭曲噪声画干草斑，形状是流线形的；
- 雪地：域扭曲噪声画出一片片偏蓝灰的阴影雪和更亮的新雪；结冰湖面的两种冰色同样用域扭曲噪声（之前单层值噪声取阈值是一块块方形）。

**峡谷（`pw_nature_gen._carve_canyon`）**——几种让地形「天然」的做法组合：
1. 台地：Simplex 分形噪声（fBm）+ 两层渐进式域扭曲（Inigo Quilez 的 domain warping，FastNoiseLite 自带），起伏弯曲不规则；
2. 峡谷网络：主河谷沿蜿蜒河道、宽度随噪声变化，谷底平、崖壁陡；反转的山脊噪声（ridged）切出分叉支沟，离主河谷越远越浅；
3. 岩层：从谷底往上每层厚 0.7~2.4 米、陡坎占 15%~45%，整体略倾斜；分层前高度加噪声，台阶边缘不是等高线；
4. 侵蚀：3000 滴水的粒子水力侵蚀（刻冲沟、坡脚堆积）→ 一遍平滑去掉单格尖刺 → 热力侵蚀（太陡处塌落成碎石坡）；
5. 着色：台地是低对比的红土贴图（canyon_soil），崖壁按世界高度画水平岩层（3 种柔和岩色 + 层间暗线），不受贴图投影方向影响。

参考：Inigo Quilez《Domain Warping》《fBm》；Hans Theobald Beyer《Implementation of a method for hydraulic erosion》（粒子侵蚀）；
Musgrave 等《The Synthesis and Rendering of Eroded Fractal Terrains》（热力侵蚀）；Red Blob Games《Making maps with noise》。

## 10. 性能基线

测量方式：`godot --path godot --rendering-driver opengl3 -- --weather=clear --hour=11 --bench=600`（关闭垂直同步，角色沿路行走，镜头跟随）。

| 指标 | 优化前（`50344d4`） | 手写小镇（`7256e9e`） | 当前（生成的小镇，80 米） |
|---|---|---|---|
| 平均帧率（M1，桌面 OpenGL） | 约 65 FPS | 约 85 FPS | **约 87 FPS** |
| 渲染 CPU 时间 | 约 2.7 ms | 约 2.4~2.9 ms | 约 2.3 ms |
| 绘制调用 / 帧 | 约 432 | 约 307 | 约 351 |
| 显存 | 67 MB | 60 MB | 62 MB |

P4 之后（像素精灵玩家 + 8 个 NPC）：约 138 FPS（不带 NPC、低模玩家 141 FPS，M1 无垂直同步），绘制调用 349（低模身体部件多，换成精灵反而少了），
显存 +40 MB（6 张 1280×1024 无损精灵表）。

性能手段（保持画质不变）：
- 静态物体按 40 米区块、按材质合批（`PWBatcher.add_static`）；
- 植被同样合批，色调和摇摆相位写进顶点数据（`PWBatcher.add_plant`）；
- 不可能投出可见阴影的平面不进阴影贴图；
- 阴影距离随镜头距离自适应；
- 辉光、读屏幕的后期只在需要时开启；
- 没有积雪时 shader 跳过积雪噪声计算。
