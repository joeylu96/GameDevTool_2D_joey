# 画面规格（当前定稿版本）

本文件记录当前画面效果所依赖的关键参数，作为后续开发的基准。改动其中任何一项前，请先在 Demo 里对比截图（见文末「验证方法」），确认画质没有退化。

- 版本基准：Godot 4.7.2-stable（GL Compatibility 渲染器），见 README「环境要求」
- 参考画面：`pixel.jpg`；目标是「远看精致、近看清晰、移动时不闪烁」

## 1. 渲染与分辨率

| 项目 | 当前值 | 位置 |
|---|---|---|
| 渲染器 | GL Compatibility（WebGL2 兼容） | `project.godot` |
| 默认分辨率 | 1280×720 窗口，**原生分辨率渲染** | `project.godot` / `PWPixelDisplay` |
| 抗锯齿 | **4x MSAA**（原生模式） | `PWPixelDisplay._update()` |
| 像素模式（可选） | 关闭；开启时约 **540p** 渲染再整数倍最近邻放大，并关闭 MSAA | `style.json: pixel_height` |
| 色调映射 | Linear | `PWTimeOfDay._ready()` |
| 辉光 Glow | 强度 0.7，HDR 阈值 0.9，bloom 0；**仅在夜晚 / 闪电 / 有积雪时开启**（`auto_glow`） | `PWTimeOfDay` |
| 后期 | 暗角 0.22（乘法覆盖层）；去饱和（阴天）、移轴只在需要时启用；移轴默认关闭（焦点 0.55，宽 0.16，模糊 2.5px） | `PWPostFX` |

## 2. 贴图与材质

| 项目 | 当前值 | 说明 |
|---|---|---|
| 像素密度 | **32 texel / 米**（1 贴图像素 ≈ 3.1cm） | `style.json: texel_density`；所有模型共用 |
| 几何对齐 | 1/32 米（`MB.SNAP`） | 与像素密度一致 |
| 贴图尺寸 | 墙、屋顶、石砖 64px（2 米循环）；草地 128px（4 米）；石板路 96px（3 米）；土路 128px；沙 / 湖底 96px | `pw_textures.gd` |
| 过滤方式 | **线性 + Mipmap + 各向异性**，shader 内做「锐利双线性」 | 近处像素边缘锐利；镜头移动时边缘约 1 屏幕像素平滑过渡（不闪）；缩小后退回 Mipmap |
| 调色板 | 56 色（`style.json`），贴图只用调色板色及其两两混合（`Pal.mix`） | 修改后运行 `python3 tools/sync_style.py` |
| 统一材质 | 所有模型用 `pixel_world.gdshader`；材质差异只在贴图和少量参数 | `pw_materials.gd` 的 `DEFS` |
| 顶点色 | RGB = 实例色调（白 = 不变）；A = 部件随机数（窗户夜间是否亮灯） | `MB.color` |
| UV2.x | 植被摇摆相位（合批后每棵树各摆各的） | `demo_town._flush_multimesh` |

### 贴图绘制规则
1. 大面积用可平铺值噪声做成片色块和多级明暗，不用逐像素随机杂点。
2. 结构线（板缝、瓦缝、石缝）1px 宽，旁边 1px 高光。
3. 细节用成簇的小笔触（草叶、针叶、石子），每个笔触有亮面和阴影。
4. 长条结构（码头甲板等）**不在贴图里画密集的高对比条纹**，缝隙用几何表现，否则远看会出摩尔纹。
5. 地面类贴图生成后 `flip_y`，保证俯视时「阴影在下」。

## 7. 场景内容与变化

- **房屋**：门窗是独立 3D 部件（`pw_parts.gd`）；门色、百叶窗、窗格数、花箱、老虎窗、雨棚、屋顶颜色按房屋参数派生。
- **树**：10 种松树 / 冷杉 + 12 种阔叶树（橡树 6、白桦 3、杨树 3，不用红 / 橙色的秋色树）+ 8 种灌木 + 8 种石头，每个实例再随机朝向（任意角度）、宽高比例（±12% / -12%~+20%）和色调（±10%），场景里没有两棵一样的树。
- **树干规则**：乔木（松树、橡树、白桦、杨树）必须露出树干——俯视 40° 时树冠外伸多少就会挡住下面多高的树干，所以树冠最低处 ≥ 树冠外伸量 × 0.85 + 0.55 米（`_clear_height`）；根部略粗。只有灌木和花草没有树干。树干、树枝用 `MB.tube` / `wrap_uv`，贴图沿圆周展开，避免横向花纹连成圆环。
- **白桦**：微弯的三段白色主干（根部 0.23 米、树梢 0.05 米）+ 3~4 根斜枝，树冠是 9~13 个相互重叠的嫩绿叶团组成的椭圆冠；树皮 64px，成簇的黑色皮孔 + 深色疤痕。
- **路灯**：4 种款式（灯笼、悬臂、球形、双头）× 3 种金属色，每盏随机；悬臂灯伸向路面，光斑对准灯箱。
- **篱笆**：3 种（白色尖头栅栏、乡村木栏、矮石墙）；**长椅**：3 种（木条、公园绿漆、原木凳）。
- **码头**：独立甲板（宽 0.26 米，缝 3.5cm）+ 托梁 + 木桩 + 系船柱。

## 8. 性能基线

测量方式：`godot --path godot --rendering-driver opengl3 -- --weather=clear --hour=11 --bench=600`（关闭垂直同步，角色沿路行走，镜头跟随）。

| 指标 | 优化前（`50344d4`） | 当前 |
|---|---|---|
| 平均帧率（M1，桌面 OpenGL） | 约 65 FPS | **约 78~82 FPS** |
| 渲染 CPU 时间 | 约 2.7 ms | 约 1.9 ms |
| 绘制调用 / 帧 | 约 432 | 约 322 |
| 显存 | 67 MB | 59 MB |

性能手段（保持画质不变）：
- 静态物体按 40 米区块、按材质合批（`demo_town._add_mesh` / `_flush_static`）；
- 植被同样合批，色调和摇摆相位写进顶点数据；
- 不可能投出可见阴影的平面不进阴影贴图；
- 阴影距离随镜头距离自适应；
- 辉光、读屏幕的后期只在需要时开启；
- 没有积雪时 shader 跳过积雪噪声计算。

## 9. 验证方法（Demo 命令行参数）

```bash
G=/Applications/Godot.app/Contents/MacOS/Godot
# 截图
$G --path godot --rendering-driver opengl3 -- --weather=snow --snap --hour=12 --screenshot=/tmp/a.png
# 静止画面稳定性：隔 20 帧比较，陆地应为 0 变化
$G --path godot --rendering-driver opengl3 -- --focus=0,-6 --distance=30 --frames=40 --gap=20 --diffshot=/tmp/d.png
# 移动闪烁：镜头平移 1cm 前后比较，看 popped（整格翻转比例），当前约 0.7%
$G --path godot --rendering-driver opengl3 -- --focus=0,-6 --distance=22 --frames=40 --gap=2 --pan=0.01,0 --diffshot=/tmp/p.png
# 帧率
$G --path godot --rendering-driver opengl3 -- --bench=600
```

其它参数：`--player=x,z` `--walk=x,z` `--focus=x,z` `--distance=米` `--yaw=度` `--snow=0..1` `--wet=0..1` `--pixel` `--tilt` `--run`；调试开关 `--noaa` `--noshadow` `--noglow` `--nopost` `--nomsaa` `--shadowmode=ortho|2|4`。
